# Chapter 4 Learning Notes

In this chapter, I learned how Git tracks changes in a project.

- A repository stores project files and their history.
- The git status command shows the current state of files.
- The git add command stages changes.
- The git commit command saves staged changes in history.
- The git push command uploads local commits to GitHub.
- The git pull command brings remote changes to the local repository.

I learned that clear commit messages help explain the purpose of each change.
